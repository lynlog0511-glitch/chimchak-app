## 0. 한 줄 원칙

흰 지면 + 헤어라인 + 조용한 회색 면. **틸은 화면당 2곳 이하**(주 CTA/마이크, 활성 표시). 배지·칩·이모지·장식 아이콘 대신 **문장과 타이포**로 말한다. 빨강은 119와 ⚑CF에만, 앰버는 "다시 볼 것"과 감정 상태에만.

## 1. 컬러 토큰 (globals.css @theme 교체값)

기존 토큰명 유지, 값만 갱신. 새 토큰은 ★ 표시.

```css
/* 지면·면 */
--color-paper: #ffffff;        /* 본지면: 흰색으로 변경 (기존 #fafaf9) */
--color-paper-2: #f5f6f6;      /* 회색 면: 카드·입력 필드·보조 블록 */
--color-line: #eef0ef;         /* 헤어라인 (기존보다 옅게) */
--color-line-strong: #e4e7e5;  /* 아웃라인 버튼·입력 보더 */

/* 잉크 */
--color-ink: #191f1e;
--color-ink-soft: #454f4c;
--color-ink-muted: #5a625f;    /* 메타·라벨 — 6.27:1 (8/6 교정: AA 미달 37건 일괄 해소, PROJECT_BRIEF §4) */
--color-ink-faint: #69716e;    /* ★ 지문·캡션 — 5.01:1 */
--color-ink-disabled: #9aa5a2; /* ★ 비활성 전용 — 읽어야 하는 고지에는 ink-muted 사용 (8/6 교정) */
--color-ink-ghost: #8a918e;    /* ★ 셰브론·도형 장식 */

/* 브랜드 틸 — 스케일 유지, 역할 고정 */
--color-brand-600: #17948a;    /* 채움: 주 CTA·마이크·진행바·활성 세그먼트 */

--color-brand-800: #14665f;    /* 강조 텍스트·활성 탭·워드마크 */

```

사용 규칙:
- 색 면(brand-tint/ok-soft/warn-soft/danger-soft)은 화면당 1~2블록.
- 그라데이션 전면 금지 (게이지 포함 — 게이지는 단색 세그먼트).
- 학습자 말풍선은 brand-tint + on-tint 텍스트. **틸 채움 말풍선 금지** (채움은 CTA·마이크 전용).

## 2. 타이포그래피

폰트: Pretendard Variable 단일 (현행 시스템 스택 유지, 외부 CDN 금지). html 16px.

| 역할 | 크기/웨이트 | letter-spacing |
|---|---|---|
| 페이지 제목 (홈 제외 각 탭 상단) | 22px / 800 | -0.01em |
| 홈 히어로(모바일) | 23px / 800 / lh 1.45 | -0.02em |
| 홈 히어로(데스크톱) | 40px / 800 / lh 1.32 | -0.025em |
| 응급 자막 (재생기) | 29px+ / 800 / lh 1.45 (md: 40px+) | -0.015em |
| 세션 헤더 제목 | 16px / 700 | -0.01em |
| 대화 대사 | 17px / 400 / lh 1.6 (데스크톱 16.5px) | 0 |
| CUE 질문 | 17px / 700 / lh 1.5 | 0 |
| 코칭 본문 | 15px / 400 / lh 1.55 | 0 |
| 리스트 행 제목 | 16~17.5px / 700 | 0 |
| 보조 설명 | 13~13.5px / 400~500 | 0 |
| 섹션 라벨 (eyebrow) | 12~12.5px / 700 / ink-muted | +0.05~0.06em |
| 메타·타임스탬프 | 11~12.5px / ink-faint~ghost | 0 |
| 하단 고지 | 10.5~11px / ink-muted / 가운데 정렬 (8/6 교정: 고지는 읽히는 단으로) | 0 |
| 실측 수치 (라이브 계측·40건 재실행 등 「방금 잰 값」) | 40px / 800 / tabular-nums | -0.02em |
| 숫자 (진행·통계·타이머) | tabular-nums 필수 | |

- 8/6 교정: 행간은 1.3(제목)·1.45(밀집)·1.6(본문) 3단으로 통합했다(/report 가림 결과 1.85만 예외). 이에 따라 CUE 질문 lh 1.5→1.45, 코칭 본문 lh 1.55→1.6 — 0.05 차이는 지각 역치 아래이고, 행간 종수 축소가 화면 간 통일감에 더 크게 기여한다는 심미 재평가를 반영한 값이다. (적용 현황 8/6 저녁: train·safety·history·report·check·홈·공용 조각 완료, emergency·for-orgs 일부 잔여 — 전체 정합 전까지 이 서술은 목표값이다.)

- 큰 글자는 위계 최상위에만. 본문을 일괄 18px로 키우지 않는다 — 대사·CUE·응급 자막·CTA만 코어 콘텐츠로 크게(브리프 §4 방어 논리 유지).
- 명조(고운바탕 등) 사용하지 않음 — 4a는 Pretendard 단일안.

## 3. 형태 언어

- radius: 말풍선 18px(화자 쪽 모서리만 4px — 인물은 좌상, 학습자는 우상), 카드·버튼 14px, 보조 12px, 입력바 24px(pill), 바텀시트 22px, 마커 사각 12px.
- 그림자: 기본 없음. 허용 3곳 — 바텀시트 `0 -10px 40px rgba(25,31,30,.25)`, 데스크톱 미리보기 카드 `0 8px 30px rgba(25,31,30,.06)`, 마이크 링은 그림자 아닌 `box-shadow: 0 0 0 3px var(--color-brand-tint)`.
- 보더: 헤어라인(line)은 리스트 행·섹션 구분 전용. 아웃라인 버튼·제안 버튼만 line-strong 1px. 카드는 무보더(paper-2 면) 또는 line 1px 중 택1 — 같은 화면에서 혼용 금지.
- 아이콘: 이모지 0건. 문자 기호만 — ‹(뒤로) › (이동) ⌄(펼침) ✓(충족, 15~17px 원형 배지 안) ↺(재훈련). 마이크는 CSS 도형(캡슐+받침), 파형은 2.5~3px 세로 막대 3~5개.
- 상태 표시: 🟢/⚪ 이모지 → **✓ 원형 배지(ok) / · 앰버 텍스트**로 전환. ⚑CF는 빨강 10px 점 + 문장.

## 4. 컴포넌트 스펙

### 4.1 세션 헤더 (모든 훈련 화면)
`‹ + [제목 16/700 + 부제 12.5 muted "N째 상황 · 대화 단계 · AI는 어르신 역만 맡습니다"] + 우측 "종료"`. 부제 앞 6px 틸 점 = 현재 계층 표시(L3 진입 시 danger 점 + "응급 단계 — 생성 0건"). 탭바는 세션 중 숨김.

### 4.2 세그먼트 진행바
CUE 수만큼 flex 균등 3px 막대, gap 3px, 완료=brand-600 / 남음=line. 응급 재생기는 danger / danger-soft. 진행률이지 점수가 아니므로 §3-1 위반 아님.

### 4.3 말풍선
- 인물: 아바타 38px 원(성씨 1자, paper-2 바탕) + **감정 링** `box-shadow 0 0 0 2px`(평온=투명, 불안=emotion-ring, 격앙=warn). 이름 줄: `박 어르신 · 조금 불안(warn-ink) · AI 가상 인물(ghost)`. TTS 재생 중이면 이름 줄 끝에 파형 3막대 + "읽어 주는 중"(11px brand-700). 본문 paper-2, radius 4/18/18/18. 아래 11px ghost 타임스탬프 "방금".
- 학습자: brand-tint 면 + on-tint 텍스트, radius 18/4/18/18, 우측 정렬, max-width 80%.
- 지문(무대 설명): 말풍선 아님 — 가운데 정렬 12.5px ink-faint 한 줄.

### 4.4 코칭 행 (FeedbackCard 대체)
박스 없음. `[✓ 17px 원형 ok 배지] + [라벨 줄: "충족 · 침착의 코칭"(12.5/700 ok-ink) + 델타 칩 "초조도 한 칸 ↓"(11.5 ok-soft 면)] + [본문 15px ink-soft] + [출처 줄 12.5 muted: 문서명 · 밑줄 "왜 이 판정인가요?"]`. 코칭(미충족)은 배지 대신 앰버 ·, 라벨 warn-ink. "왜 이 판정인가요?" 펼침에 판정 경로(규칙 id/분기 패턴/버튼)와 루브릭 행동지표 문장 — 점수·앵커 숫자는 비표시.

### 4.5 컴포저 (CueResponder)
상단 헤어라인. `[CUE 질문 17/700 + 우측 "여유 N초"(12px disabled, tabular)]` → 제안 버튼 목록(48px+, 흰 바탕, line-strong 1px, radius 14, 좌정렬 15px/500) → `[입력바(48px pill, paper-2, placeholder "직접 입력…") + 마이크 원 52px brand-600 + tint 링]`. 재촉 어휘 금지 — "남은 시간" 대신 "여유".
녹음 중(4b): 로그 영역 opacity .45, paper-2 면 카드에 `[빨강 8px 점 + "듣고 있어요" + 파형] + 실시간 자막 16.5px + 캐럿`, 마이크는 brand-800 + 이중 링, 아래 "손을 떼면 전송돼요 / 잘못 들렸다면 보내기 전에 고칠 수 있어요".

### 4.6 ⚑CF 바텀시트 (CriticalInterrupt)
전면 딤 `rgba(25,31,30,.32)` + 흰 시트 22px. `[빨강 10px 점 + "잠깐, 여기서 멈춥니다" 19/800]` + 이유 15.5px + 근거 박스(paper-2, 13px, **"판정: 규칙 사전 CO-01 (AI 아님)"** 명시) + "대신 이렇게 말해볼 수 있어요" 라벨 + 대안 3버튼(제안 버튼과 동일 스펙) + 주 CTA "같은 장면에서 다시 해보기 — 벌점 없음". 좌측 액센트 바·빨강 헤더 밴드 금지.

### 4.7 엔딩 (EndingPanel)
- 충족(6a): ✓ 54px ok 원 + eyebrow + 제목 22/800 "말이 먼저 나왔습니다" + 소요시간. "잘한 것 N"(ok-ink 라벨) 헤어라인 리스트(3개 + "외 N개 ⌄") → "다시 볼 것 N"(warn-ink) → CTA: 주 "다음 상황으로 — {다음 시나리오}"(56px) / 보조 2분할 "이 훈련 보고 연습 · 기록 보기" / 각주 "점수가 아닙니다 — 다음에 볼 지점 안내예요".
- 재훈련(6b): ↺ 54px warn-soft 원. 제목 **"한 지점만 다시 보고 가겠습니다"** (CF 모달 문장과 반드시 다르게) + "재시도로 회복하셨어요 — 벌점이 아니라…" 부제. paper-2 카드 "다시 볼 장면" 1개 → "그래도 잘한 것 N" 리스트 → 주 CTA "같은 장면 다시 해보기 — 벌점 없음".

### 4.8 응급 목록 (5b) / 재생기 (6d)
- 목록: 페이지 제목 + 초록 점 "기기에 저장됨 —" 상태줄(미저장 시 이 줄이 앰버 문구로 교체 — 배지 2개 동시 노출 금지). 119 버튼 58px danger 채움 상단 고정(캡션 "누르면 전화 앱이 열립니다 — 훈련 중에는 누르지 마세요" 13.5px, 버튼 밖 흰 지면(8/6 교정: tel:119는 실제로 전화 앱을 열므로 「발신 안 됨」은 사실이 아님 — 정직 문구로 통일)). 5종 = 헤어라인 리스트: 한 글자 마커 42px(danger-soft 면 + danger-ink, radius 12) + 제목 17.5/700 + 행동 한 줄 12.5 muted + ›.
- 재생기: "안내 종료" + "기도폐쇄 · N / M". danger 세그먼트 진행바. 119 버튼 유지. 본문 = 파형 + "읽어 주는 중 — 자막과 같은 속도"(danger-ink) + 자막 29px/800 + **주소 카드**(paper-2: "방문지 주소 · 훈련용 더미" 12px + "○○구 ○○로 00" 21/800) + "다음 —" 예고 13.5 faint. 컨트롤 3버튼: 이전/잠시 멈춤(아웃라인) + 다음 단계(틸, flex 1.4). 각주 "사전 검수된 고정 문구 · AI 생성 아님 / 신체 술기는 119 상황실이 목소리로 직접 지도합니다". protocols.ts의 screen 지시문("119 버튼 60% 확대" 등)은 렌더 금지.

### 4.9 보고 3단계 (6e)
스텝 인디케이터 = 텍스트+헤어라인: `① 말하기 ✓(ok-ink) — ② 가리기(brand-700/800 활성) — ③ 확인(disabled)`. 가림 결과 = paper-2 문단(16px/1.85) 안 **인라인 칩**(brand-tint, 6px radius, 700): 대상자·기관·번호. 아래 범례 12px "성명 → 대상자 · …". 초안 5칸 = 헤어라인 행(라벨 64px muted + 값 600), 빈 칸 값은 warn-ink 700 "채워 주세요 — 지금 어떠신가요?". CTA 주 "확인으로 넘어가기" + 보조 "다시 말하기".

### 4.10 리스트 행 · 카드 · 탭바
- 표준 행: `[좌 42px 마커(선택)] + [제목 16~17.5/700 + 설명 12.5~13.5 muted] + [› ghost]`, 행간 헤어라인, 세로 패딩 14~16px.
- 시나리오 카드(7a): paper-2 면 radius 14 — eyebrow(유형·소요) + 제목 17/700 + 한 줄 요약 13.5 + 하단 [해 본 횟수 | "연습하기 ›" brand-700]. **LO/RE/SA/CO 루브릭 코드는 카드·브리핑 기본 노출 금지** — "이 훈련의 설계 보기 ⌄" 접힘 안으로.
- 탭바: 텍스트 5개 균등(홈·훈련·응급·보고·성장), 활성 = brand-800/700 굵기(응급 탭 활성만 danger-ink), 비활성 ink-faint. 이모지·아이콘 없음. 상단 헤어라인. 세션·재생기 화면에서는 숨김.
  - 2026-08-06 교정(팀장 승인): 4번째 탭 「기록」→「보고」. "기록"이 /report(보고 연습)와 /history(성장 기록)에 걸쳐 있어 저장된 보고를 어느 탭에서 찾을지 모호하다는 5관점 재평가 지적 반영. 「성장」은 감정 설계(점수가 아니라 성장) 유지를 위해 존치.

### 4.11 고지 (DisclaimerBar)
고정 바 폐지 → 각 화면 스크롤 끝 + 컴포저/CTA 블록 하단에 10.5~11px ink-muted 가운데 한 줄(8/6 교정: ink-disabled는 비활성 전용). 문구 불변: "훈련·교육 목적이며 119 신고, 의료인의 진단·처방을 대체하지 않습니다". 모바일 하단 safe-area 28px 확보(홈 인디케이터와 겹침 금지).

## 5. 화면별 요점 (시안 id ↔ 라우트)

## 9. 8/23 교정 — 구현이 가이드보다 앞서간 확정값

구현이 이미 확정해 굳힌 값인데 위 본문(§1~§8)이 아직 옛 값을 적고 있는 지점을 여기 못박는다. 후속 작업이 본문을 근거로 이 값들에서 퇴행하지 않는 것이 이 절의 목적이다 — 충돌하면 이 절이 §1~§8보다 우선한다.

1. **주 CTA 채움 = brand-700** (§1은 brand-600으로 적어 두었으나 CTA에는 쓰지 않는다). brand-600(#17948a) 위 흰 글자는 대비 3.72:1로 AA(4.5:1) 미달이라 17px 이상 CTA 라벨에 못 쓴다 — brand-700(#157f75)은 4.86:1로 통과한다. brand-600은 마이크·진행바·상태 점처럼 "누르지 않는 표시"에만 남긴다. 근거: `src/components/BigButton.tsx` 24~36행.
2. **제안 버튼 라벨 = 17px / 500** (§4.5는 "15px/500"으로 적어 두었다). 버튼만으로 완주하는 사용자가 세션 내내 읽고 판단해서 누르는 문장이므로 코어 콘텐츠 하한(17px, §2)을 그대로 적용한다. 근거: `src/app/train/_components/CueResponder.tsx` 673·683·694행.
3. **컴포저 내부 스크롤 — 재확인**: 모바일은 페이지 스크롤 하나이고 컴포저 도크는 그 안에 붙박이로 선다(§5 "내부 스크롤 박스 제거"는 그대로 유효) — 도크 전체가 페이지와 별개인 스크롤 박스가 되는 것은 여전히 금지다. 단 도크 가운데 켜(제안 버튼·입력창)만 상한(dvh)을 넘는 만큼 좁게 `overflow-y-auto`로 스크롤하고, 위 켜(CUE 질문)와 아래 켜(마이크·직접 입력)는 상한과 무관하게 항상 보인다 — 이 좁은 예외가 없으면 글자 크기를 키웠을 때 마이크 버튼이 화면 밖으로 밀려난다. 근거: `CueResponder.tsx` 110~124·623~635행.
4. **미충족 코칭 라벨 = warn-ink** (§4.4에 이미 적혀 있고, 구현도 이번에 맞춰졌다 — 회귀 금지). 예전 구현은 ink-soft(보조 본문과 같은 회색)를 썼는데, 엔딩 화면의 "다시 볼 것"이 이미 warn-ink라 같은 판정 뜻이 화면마다 다른 색으로 갈렸다. 근거: `src/app/train/_components/constants.ts` `COACH_HEAD_TEXT`, 257~268행.
5. **하단 고지(InlineDisclaimer) md = 11.5px 확정** (§2 표는 "하단 고지 10.5~11px"로 적어 두었다 — 목록 화면 하단에 쓰는 md 단은 그보다 0.5px 크다). 고지는 장식이 아니라 **읽어야 하는 문장**이므로, 「고지는 읽히는 단으로」라는 8/6 교정 방향을 크기에서도 한 눈금 더 밀어 둔 값이다(같은 교정으로 색도 시안의 2.54:1에서 ink-muted 6.27:1로 올렸다). 두 단은 자리로 갈린다 — sm 11px은 세션 입력 도크 아래, md 11.5px은 목록 화면 맨 아래. 근거: `src/components/InlineDisclaimer.tsx` — `size` prop 주석과 `text-[0.7188rem]`(= 11.5px) 분기. 컴포넌트 주석과 이 항목이 같은 값을 적고 있으며, 어긋나면 이 절이 §2보다 우선한다.
